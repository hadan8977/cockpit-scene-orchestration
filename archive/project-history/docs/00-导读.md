## 一页结论

- 做，但目标从“一句话生成场景 JSON”改成“车认得生活里的时刻，主动布置好，说一句话，可撤销，越用越准”。
- demo 的问题在能力表，不在模型：35 个条件全是舱内开关，没有时间、地点、人、天气、行程。
- 投入产出比最高的是 L1 派生语义，第一批做日历（含调休）、昼夜、位置、天气。仅“工作日”一项，2026 年按周几判断会错 25 天。
- 模型只在创建、建议、解释时运行；执行走车端规则引擎。
- 主动要克制、可见、可撤销；记忆要可见、可删；第一版身份识别不用人脸。
- 社区先做官方季节包，看安装率再扩。
