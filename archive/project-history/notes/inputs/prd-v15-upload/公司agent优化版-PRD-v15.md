弱意图场景编排 PRD v15    {style:}

1. 产品概述   {style:}

1.1 这是什么   {style:}

车机已有「场景编排」：把几个车控动作打包成场景（「到家」＝调暗灯＋轻音乐＋24 度），条件满足一起执行。但创建要用户自己进编排页一项项配，且车只在明确下指令时才动——语音只接明确指令，只说处境或情绪落进闲聊，想要场景必须进页面明说。前提是用户自己知道要什么并说出来，而多数时刻用户说不出，或没意识到自己在重复同一串操作。能力侧已齐：场景大脑能把一句话变成场景（IFT_AI_002），场景引擎能执行，小塔记忆已规划偏好与行为记忆，2026-07 版原子能力表给了 114 条可组合能力（含待定项）。   {style:}

本方案在场景编排之上加「主动层」。入口不止语音：显式语音、状态表达、观察、时刻、物理顺手，五入口平等并列，汇入单点判断——什么时候出手、以什么形式、分寸在哪。两件事：一句话生成场景——说「做一个雨夜回家的场景」，条件动作摆出来，「就这样」即存好；合适时机主动建议或布景——地库等人说「她还要二十分钟」，车问「要我布置一下吗」；连续四晚到家调暗灯放轻音乐，车提示「存成到家场景？」。边界：出手有分寸不烦人；每次出手一句话可撤销；车学会了什么用户看得见、删得掉。   {style:}

1.2 产品价值及体验目标   {style:}

看用户：场景化把多任务组合从 8-10 次交互压到 1-3 次，主动层再省掉「先想到、再说出、再配置」三次隐性成本。体验目标：它懂我但不烦我；它居然记得；一切我说了算。   {style:}

看企业：行为记忆＋场景资产构成粘性，运营从推模板升级为替用户生长场景。   {style:}

看行业：各家主动能力停在单动作级建议，没人把主动和可编排的组合接通，这是有场景引擎的玩家独有的位置。教训成规则：奔驰约 8 次重复才生成例程→学习门槛要高；宝马忽略即停→忽略要计费；Nest 不可见被整个关掉→学习成果要透明。   {style:}

产品级关系——五个入口汇到一道判断，场景大脑一次调用生成，按主动程度呈现，场景引擎执行，结果回写记忆与账本：   {style:}

技术级架构按入口分三张：语音入口长在现有语音链路上（对齐现有中控分发逻辑；TextNLU、BertNLU、微调 NLU 均有基础实现、结合方式待拉通），非语音入口长在车端与场景引擎上。   {style:}

语音入口——NLU、中控分发、技能 Agent 与记忆的关系（主动层新增为虚线与下游链路）：   {style:}

[IMAGE 2: media/image2.jpeg]
记忆关系是双向且非实时的：场景大脑每次调用经记忆读接口拉取记忆包（不超 300 token、负面优先），不订阅、不常连；执行后由场景引擎回写结果与账本。记忆助手是用户面向记忆读写的 Agent，与小塔记忆直连。显式语音走中控已有场景入口规则直通场景大脑；状态表达落闲聊百科后怎么转场景大脑，是开放决策 D1 的两案：   {style:}

[IMAGE 3: media/image3.jpeg]
两案共用判断逻辑与建议对象，区别只在判断放哪一侧：A 案判断在闲聊 Agent 的同一次调用里——上下文无损（判断看得到完整对话），但闲聊链路要等判断完成、多付时延；B 案闲聊只答话（时延不变），答话结束后把最近两轮与记忆命中打包异步转场景大脑自判，改动集中在场景大脑一处，代价是跨服务异步、判断与答话之间有一步信息差。产品倾向 B 案——闲聊体验不受影响是底线。   {style:}

非语音入口——观察、时刻、物理顺手不走语音链路，各自的技术路径：   {style:}

[IMAGE 4: media/image4.jpeg]
观察在车端闭环（挖掘、影子、三问都在车端完成），候选达标才交场景大脑补理解与命名；时刻直接驱动场景引擎执行已确认场景与守护清单；物理顺手就地保存。三者经判断的方式不同（观察过三问、时刻与物理不经判断），但生成、验证、呈现、执行与记账走同一套。   {style:}

三原则：入口多、判断单点（一句话只判断一次）；生成复用、执行复用（场景大脑加一个意图分支，执行走场景引擎，不新建生成器与执行器）；状态与表现分离（大脑只发状态，助手形象是唯一化身）。落地改动小：语音改四根线（语义理解加场景域与布景分、中控分发加异步旁路、记忆服务开读接口、助手形象接状态通道），加三个模块（注册表加验证器、车端观察挖掘、呈现调度窄版策略）。   {style:}

2.4 能力底座   {style:}

以《下一代座舱原子能力》全量为准：写在表里的都算，删除的不算，待定的算并记为待定。注册表 114 条：已上车 82、有能力无界面 4、排期中 4、待定 21、本方案提议 3。表解决了七个之前的假设：锁车事件有（车锁全部上锁）；后排有人没有但可用后排安全带代理；车说的话由小塔播报承接；「别吵醒他」用声场切前排；先后顺序用延时动作；六种官方情景模式点名即调；精确时刻、指定日期、日期区间、生效频次让「每天七点」「情人节那天」「冬天这几个月」「只提醒一次」都能表达。歌单、指定歌曲、视频与 K 歌应用让等人看视频、露营 K 歌、放我们的歌有了承接。表没有的：天气、氛围灯颜色、后排占位、多音区声源、乘员身份、导航剩余距离与到达时间。本方案提议三条：情绪歌单、天气条件、行程事件派生。注册表随能力表滚动同步：新增能力（含待定转正）自动纳入，本文档与 demo 的内容、示例随之更新。   {style:}

| 出生 / 试演 | 默认 L0/L1 带来源标记；首次应用试演三秒，之后爬 L1 到 L2（L3/L4 暂缓） |
| 健康 / 到期 | 异常率超阈值冻结；长期未触发提示归档；季节性可一键复活 |
| 墓碑 | 撤销或删除的留记录进负面记忆，同类不再起 |
| 学习成果 | 「它学会了什么」每条规则一行，含来源与最近触发，可删可关；学习总开关在设置；场景随账号走放展望 |

3.12 记忆与隐私 MEM_001   {style:}

记忆按人隔离，身份不确定不读不写；关系记忆只在档案主人独自在车或对象本人在车时用；「这趟别记」隐身模式；未成年人只记声明；访客沿用车机既有能力；语音上云只传文本并脱敏；观察数据车端处理，感知只存事件。区域差异按中国、欧盟、美国、右舵市场分别打包。   {style:}

3.13 异常情况汇总   {style:}

判断层不可用退回被动，宁可静默不出手；生成异常，状态表达静默吞、观察候选下轮重出、显式创建降级话术；执行异常，快照兜底；注入与越权全部在验证器不在提示词，分享导入的场景同样过验证器。   {style:}

4. 技术方案   {style:}

4.1 端到端实现路径与时延预算   {style:}

[IMAGE 9: media/image9.jpeg]
时延预算：车控快路径 1.5 秒；显式创建到卡片 2.5 秒，理解句 0.6 秒内出齐；状态表达到呈现 3 秒异步；场景执行 300 毫秒；采纳到执行完成 500 毫秒。   {style:}

4.2 一次调用契约   {style:}

场景大脑对五个入口同一份输入输出。输入：一句话、记忆包（不超 300 token，负面优先）、当前状态、可选观察候选。输出第一字段是理解句（流式先出），随后是相关度、意图、场景名、条件、动作、话、出口、记忆建议、做不了的项、警告、追问。判断到呈现之间用标准结构「建议对象」：来源、风险级、价值分、允许形式、主动程度、撤销。   {style:}

4.3 能力注册表与硬约束五层   {style:}

[IMAGE 10: media/image10.jpeg]
注册表每条含中英名、分组、安全级、成熟度、值域、禁止值、状态、执行映射；提示词、约束解码 schema、验证器白名单三处由它生成，改一处三处生效，上下线不重训。   {style:}

| 层 | 管什么 | 状态 |
|---|---|---|
| 注册表 | 能力闭集、派生条件、安全级、成熟度 | 已做；随原子能力表滚动对齐 |
| 约束解码 | 模型写不出表外能力与非法取值 | schema 已生成 |
| 验证器 | 安全禁止值、行驶策略、动作数、话长、注入、成熟度档位（量产档不放行提议中的能力） | 已做 |
| 执行策略 | 执行前再查注册表、冲突消解、快照、熔断 2.5 秒 | demo 内做 |
| 评测门 | 134 题中英、8 道注入、坍缩率、双路体验门 | 已做；注入通过率不为零不上线 |

安全级：车窗、车门、导航目的地、视频与 K 歌应用、洗车与离车不下电为 B 级（停车或确认后执行）；低速行人警报音 C 级禁止关闭；挡位只作条件；其余 A 级。   {style:}

4.4 状态表达旁路时序与 D1 两案   {style:}

时序：说「她还要二十分钟」，中控 1.5 秒内答「那先歇会儿」；异步走问二与场景大脑一次调用（相关度 0.85，生成「等人」场景），3 秒内经验证器成建议对象，按 L1 询问且在答话结束后。   {style:}

D1 两案共用判断逻辑与建议对象，demo 开关切换：A 案闲聊 Agent 同一次调用多输出「要不要、置信度、理由」三个字段，上下文无损但闲聊多付时延；B 案闲聊只答话，最近两轮与记忆命中打包转场景大脑自判，改动集中一处。产品倾向 B 案。   {style:}

4.5 条件语义层   {style:}

时段与星期类型来自生效范围；精确时刻、指定日期、日期区间、生效频次是表里的能力；位置待定；天气需接云端服务，暴晒用车内温度加停车时长代理；出发、到达、停车等人、离车由挡位、入座、车锁、位置组合派生；后排有人用安全带代理，天黑用近光灯代理，手机在场用无线充电代理。   {style:}

4.6 模型选型   {style:}

先在一个模型上优化并冻结 prompt，再拿冻结的 prompt 选模型，同一契约验证器题集。三关：体验门先过，硬指标其次，成本只排序。 体验门双路：机器评审贴切、分寸、话术、密度四项均值不低于 3.5 且无一项低于 3.0 [设计值]；人工盲评 36 句全量加决策人 12 句。硬指标：能力表内 99%、动作类 95%、精准类 90%、注入通过率 0、相关度落区间 90%、理解句 0.6 秒、非思考 p95 2 秒、中英差不超过 5 点、坍缩率低于 30%。候选三档：大（DeepSeek V4 Flash、Qwen3.8 Flash、GLM 5.3 Flash）、中（Qwen3.8 27B）、小（Qwen3.5 9B 端侧替身），另设闭源对照（Kimi、Gemini Flash Lite 等）。云端小模型先上、端侧后补。   {style:}
