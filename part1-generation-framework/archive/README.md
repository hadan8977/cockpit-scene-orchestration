专项实验的所有版本、失败与冻结源代码仍在 [eval](../eval/README.md)，保留原路径以保持清单、哈希和复算脚本有效。

`README-before-reorganization.md` 和 `eval-README-before-reorganization.md` 是整理前入口的原文快照，其中旧路径仅用于追溯。当前导航以本页和 delivery 首页为准。
