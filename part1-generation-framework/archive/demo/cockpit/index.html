设计依据

全景带借 BMW Neue Klasse 的 Panoramic Vision 思路：把要一眼看的放在 A 柱到 A 柱的一条带上。零层卡借 MBUX Zero Layer：不进菜单，情境卡直接停在拇指区。氛围灯只做场景色载体、默认低亮，参考奔驰 Vision EQXX 与 Polestar Precept 的“光线即状态”。以上为公开概念的设计原则借鉴，不复刻界面 [常识，未核实细节]。人体工学阈值：字高 ≥ 5mm@75cm、触控 ≥ 9mm、单次注视 ≤ 2s、行驶中选项 ≤ 3 [常识]。
