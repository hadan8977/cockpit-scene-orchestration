# 座舱原子能力表（2026-07 版）对照结论

来源：`notes/inputs/座舱原子能力-最新.xlsx`（变更记录到 2026.7.7），五张表：变更记录、当满足条件、就执行、生效范围、说明。逐行导成注册表 v2：`eval/import_capabilities.py` → `eval/vocab.json` → `capabilities.json`，114 条：能力表里非删除的一级能力 125 项（条件 57、动作 68，同名合并后 111 条）全部收录，含全部待定项；另加我们提议 3 条。成熟度：已上车 82、有能力无 UX 4、排期中 4、待定 21、提议 3。口径：只要写在表里的都算，标「删除」的不算，标「待定」的算并记为待定。旧表（同事两年前 demo，56 条）留作 `vocab_v1.json`，只给 p0 到 p2 三个旧 prompt 打分用。

## 1. 它解决了什么

| 之前待确认 | 表里的答案 | 对方案的影响 |
|---|---|---|
| 解锁与锁车事件 | 有：车锁 有门未锁 / 全部上锁 | 离车事件成立：全部上锁加主驾无人。出厂守护清单的“离车忘关窗”可做 |
| 后排占位 | 没有。有主驾、副驾、任意位置的入座离座 | 用后排安全带系上作代理；PRD 里“后排有人”条件改为安全带 |
| “话”这个元素有没有能力承接 | 有：小塔播报 输入内容 / 播放天气 | 契约里的 say 直接落到小塔播报，不再是设计假设 |
| “别吵醒他”怎么做 | 有声场：全车 / 前排 / 主驾 | 正解是声场切前排加降音量，不是停播。旅程一第 3 拍照此改 |
| 场景内先后顺序 | 有延时动作，0 到 59 分 59 秒 | 时间线（灯 2 秒淡入、声 3 秒淡入）有了执行原语 |
| 官方预设 | 有情景模式：休憩、露营、洗车、后排查看、离车不下电、多人同乘隐私（待定） | “预设是地板”落实：用户点名时调预设，不重新拼动作；场景大脑可在预设上加改 |
| 时段与星期 | 有生效范围：时间段、每天 / 周末 / 工作日 / 自定义、日期区间、生效频次（待定） | 时段与星期类型是真实的生效范围，不是我们发明的条件；节假日与调休仍要节假日表 |
| 位置与导航 | 位置 在某地 / 不在某地（家、公司、收藏地点）待定；导航目的地 家、公司在 26409 | 地点类条件可做但排期未定；“到家前 1 公里”不可做 |
| 惊喜 | 有彩蛋：生日动效、情人节动效 | 庆祝类场景多一个元素，写进六元素语法作第七种 |
| 屏幕 | 白天 / 黑夜模式、亮度 0 到 100 | 光元素扩到屏幕 |

## 1b. 待定项也算进来之后多了什么

| 待定或排期中的能力 | 能做的新场景 |
|---|---|
| 生效时间（精确时刻）、生效时间段、重复周期、日期区间、指定日期、生效频次 | 「每天早上七点」「情人节那天」「冬天这几个月」「就提醒这一次」都能直接表达；季节包、纪念日、一次性场景有了执行原语 |
| 位置在某地 / 不在某地、导航目的地（含收藏、常用、搜索） | 到家、到公司、到某个收藏地点的场景；导航回家作为出口 |
| QQ音乐与网易云音乐的歌单、播放指定音乐 | 「放我喜欢的歌」「放我们的歌」有了真实承接；情绪歌单的提议可以映射到猜你喜欢与指定歌曲 |
| 本地视频、腾讯视频、爱奇艺、唱吧、全民K歌、酷狗K歌、YouTube 打开退出 | 停车等人看视频、露营 K 歌、后排查看；一律停车态、B 级 |
| 四门开关 | 停车且确认后才动 |
| 六种官方情景模式、彩蛋自定义动效、壁纸与主题 | 预设之上加一件事；屏幕作为光元素的一部分 |

题集因此加了 S 类 8 题：情人节惊喜（指定日期加彩蛋）、冬天座椅加热（日期区间）、明早八点提醒一次（生效时间加频次）、等人看视频、露营 K 歌、放我喜欢的歌、周末换亮主题、三周年纪念日；B11「每天早上七点」改为可直接表达。题集共 134 题。

## 4. 我们提议、表里没有的三条

| 能力 | 为什么要 | 怎么落 |
|---|---|---|

## 5. 安全级与本方案的政策

表本身不带安全级。本方案给的：车窗、车门、导航目的地、进入情景模式（洗车、离车不下电）为 B 级，停车或确认后执行；挡位只作条件；低速行人警报音 C 级并禁止关闭；其余 A 级。车门作为动作是表里的待定项，本方案在行驶中一律不动，停车也要问哪扇门。

## 6. 成熟度在产品里怎么用

注册表每条带成熟度。prompt 里排期中与待定的能力标“（规划中）”，提议的标“（提议，需共建）”；模型可以用，但同一场景最多一个并写进 warnings。验证器有两档：量产档只放已上车与有能力无 UX 的；demo 档全放，卡片上把规划中的 chip 用虚线描边标出来。选型评测按 demo 档跑，选型报告里同时给量产档的通过率。

## 7. 对题集的改动

题集 114 题扩到 126 题，再加 S 类到 134 题。改：B10、B11、B15 的天气与时段条件；H 类观察候选用位置替代地点；E、F、G 类里的律动、按摩、后排座椅值域。新增 N 类 12 题：别吵醒他（声场）、冷死了快点热（极速升温）、锁车后关窗（车锁加任意车窗）、后排有人开加热（安全带代理）、进入露营模式（官方预设）、带自定义动作的露营场景（预设加自组加延时）、今天我生日（彩蛋）、手机放上去了（设备类不是布景）、开近光灯切黑夜模式（车外灯作条件、屏幕作动作）、换行人警报音色（允许换音色不允许关）、导航回家路上安静（规划中能力要标 warnings）、开门（B 级要追问）。离线自检 126 题全过，噪声版能检出。
