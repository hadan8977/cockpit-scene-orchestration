## 5. 体验门：双路

**机器路** `judge.py`：评审模型对情绪、模糊、弱意图、记忆、显式、观察、追问七类输出打四项分（贴切、分寸、话术、密度，1 到 5）并给六个旗标（说教、推销、追问原因、假设关系、复述情绪、功能性误用）。评审模型与被评模型不同；相同时报告注明只作参考。门槛设计值：四项均值不低于 3.5 且任一项不低于 3.0。

**人工路** `blind_pack.py`：36 句盲评集（`blind_set.json`，情绪 10、模糊 4、弱意图 8、记忆 4、显式 6、追问 2、鲁棒 2），候选匿名成 A/B/C 随机排序，生成 `sheet.md` 与 `ratings.csv`。全量由我评；用 `--sample 12` 抽 12 句给你评，同一评分表。评完 `blind_pack.py score` 汇总回模型，并与机器路对照一致性。

评分定义：
- 贴切：抓住原话关键词并落到对的元素；答非所问或套模板 1 分。
- 分寸：该少则少；闲聊、抱怨、满意的感叹不当需求；负面记忆不再出现；行驶中不做大动作。
- 话术：短、自然、引用原词、不说教、不追问原因、不解释；不需要说时不说也是满分。
- 密度：动作数与元素搭配；什么都不做有时满分；四个以上几乎总扣分。

## 8. 怎么跑

```bash
cd cockpit-scene-orchestration-r2-20260902/eval
export DEEPSEEK_API_KEY=... OPENROUTER_API_KEY=...          # KIMI_* 已在环境里
python3 run_matrix.py --check                              # 核对模型 id
python3 run_matrix.py --role 主候选 --prompts p3 --thinking off --judge      # 第一轮
python3 run_matrix.py --keys ds-v4-flash,qwen3-30b-a3b --prompts p3,p2,p1 --thinking both --repeat 3 --response-format json_object   # 第二轮
python3 blind_pack.py build --tags matrix-<日期>/ds-v4-flash__p3__off,matrix-<日期>/qwen3-30b-a3b__p3__off --out blind/<日期> --sample 12
python3 export_cases.py --tag matrix-<日期>/ds-v4-flash__p3__off       # 原型回放数据
```
结果：`results/matrix-<日期>/compare.md` 一张总表加门槛对照；每次运行有 `summary.md`、`judge_summary.md`。

## 10. 冒烟结果（Kimi K2.7，p3，非思考，中文，32 句）

| 类 | 通过 | 主要失败 |

| 观察 | 6/6 | |
| 追问 | 6/6 | |

relevance 落区间 19/20。坍缩率精确 8%、宽松 42%，宽松高说明元素组合在收敛到示例。理解句出齐 p50 6.1 秒，这个端点整体慢，不代表模型。三点直接影响 prompt 变体：示例要轮换并去掉「按摩」组合；负面记忆要写成硬规则；`understanding` 里禁止用 ASCII 引号或改 json_object 模式。
