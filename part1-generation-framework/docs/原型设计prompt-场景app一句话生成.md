# 原型设计 prompt：场景 app「一句话生成」

用途：交给 Figma Make 或 kimi 生成高保真前端。正文可整段粘贴。对应 PRD v14 的 GEN_001 与 4.3 体验与视觉规范；参考实现见 `demo/gen-app/index.html`（回放真实模型输出，数据在 `cases.json`）。

---

请设计一个车机中控屏上的「场景」应用页面，功能是「说一句话，生成一个座舱场景」。画布 1280 × 720（15.6 寸横屏），暗色座舱主题，给驾驶员在停车时使用。要求如下。

**页面结构**
1. 顶栏：左侧应用名「场景」，右侧两个胶囊开关「中文 / English」与「内部版」。内部版打开时，右侧出现一个 380 px 宽的侧栏。
2. 主区从上到下：
   - 输入行：麦克风圆点、单行输入框（占位文字「说一句，比如：做一个雨夜回家的场景」）、一个金色主按钮「生成」。
   - 一行可点的示例句胶囊，颜色低调，悬停变亮。
   - 一张结果卡片，左侧有 3 px 场景色描边。卡片内容按出现顺序：
     a. 小字「听到的：」加用户原话（原话加粗），右侧灰字显示上下文（如「19:20，停车中，商场地库」）。
     b. 场景名，20 px 半粗。
     c. 理解句：一行正文，必须包含用户原话里的词（用引号标出）。这一行是流式逐字出现的，尾部有闪烁光标。
     d. chips 分组，左侧 34 px 灰色小标签，依次为：条件、光、声、气、温、话、供，再加「其他」与「记忆」。每个 chip 显示能力名和金色的取值，如「氛围灯亮度 30%」。chips 在理解句之后逐个淡入。
     e. 被裁掉的 chip 用灰色虚线边框加删除线，并在右侧用橙色小字写理由，例如「法规不允许关」「行驶中亮度不超过 50%」「做不了」。
     f. 记忆 chip 用蓝灰边框，前缀「用到了：」或「建议记住：」，右侧有一个小 ×，长按删除。
     g. 一行「说」：助手会说的一句话，带引号；如果不说话就显示灰字「不说话」；如果是追问则前缀「问」。
     h. 三个键：「试一下」（次要，本期置灰并带提示「试演三秒，第二部分接场景引擎后启用」）、「就这样」（金色主按钮）、「不用」（幽灵按钮）。右端一个小字链接「为什么」。
     i. 一行「再说一句，只改一处」的输入框加「改」按钮。改动后只有对应的一个 chip 高亮闪一下并更新取值，其余不动。
3. 内部版侧栏（给产品与工程看，决策层演示时关掉）：
   - 「模型与 prompt」下拉框。
   - 「时延（真实测量）」：一条 0 到 3 秒的进度条，上方两个刻度标记「0.6s 理解句」「2.5s 卡片」，进度条上两个圆点分别落在实际的理解句出齐时刻与输出结束时刻；下方键值对：首字、理解句出齐、输出结束、意图 / 相关度、验证器（通过 / 有裁剪）。
   - 「路由与裁决」：五个步骤点，绿色表示经过、橙色表示有裁剪：语音入口、门控、场景大脑一次调用、验证器、呈现调度。
   - 「场景中心」：保存后的场景列出一行，右侧灰字写「有触发条件」或「手动」。

**视觉与动效**
- 背景 #0d0f13，面板 #151922，次级面板 #1c2230，描边 #2a3243，正文 #e8ebf1，弱化文字 #8a93a6，禁用 #5b6373。
- 场景色只来自「光」元素（默认暖金 #c9a46a），用于卡片描边、主按钮与 chip 取值文字。其他文字一律中性。
- 卡片进场 300 毫秒、退场 200 毫秒，轻微上移淡入。chip 淡入 250 毫秒并从 0.96 放大到 1。
- 无音效。字体系统默认无衬线，中文优先。
- 行驶中状态：卡片只显示「摘要态」三行（听到的、场景名、说），不展开 chips；顶部出现一条细的「行驶中」提示。请为摘要态单独出一个画面。

**状态与画面清单（请分别出图）**
1. 空态：只有输入行与示例句。
2. 生成中：理解句正在逐字出现，chips 还没出。
3. 完成态：全部 chips，其中一个被裁掉灰显（理由「法规不允许关」），一个「做不了」（表外能力），一条记忆 chip。
4. 改一处：用户说「灯再暗点」后，亮度 chip 从 30% 变 15% 并高亮。
5. 追问态：场景名为空，「说」一行变成「问：要开哪一排的？」，只有「不用」与再说一句可用。
6. 无需布景态：用户说「明天几点开会啊」，卡片只显示「听到的」与灰字「这句不需要布置什么」，无 chips 无按钮。
7. 行驶中摘要态。
8. 英文版完成态（同一结构，理解句与「说」为英文，能力名仍是中文）。

**文案规则**
引用用户的词；不夸不推销；不解释自己做了什么，除非用户点「为什么」；中文 15 字内，英文 8 词内；要求安静时最多 4 个字或不说。

**不要做**
不要轮播，不要同时出现两张卡片，不要弹窗，不要用彩色渐变背景，不要在卡片上显示置信度或模型名（这些只在内部版侧栏）。
