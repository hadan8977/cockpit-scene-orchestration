# 第一部分测试计划 v2：先把 prompt 优化好，再选模型

取代 v1.2。改动：把「prompt 优化」从模型选型里拆出来，作为独立的第一阶段，在 DeepSeek V4 Flash 上用同事版本作 v0 起步，做 A/B 与消融，逐轮记录，直到得到一版安全、稳定、快速、质量均衡的 prompt 并冻结；第二阶段再拿冻结的 prompt 在 DeepSeek V4 Flash 与 OpenRouter 17 个模型上选型。日期 2026-09-08。

## 1. 结论先行

- 两个阶段，两个对象。阶段一只动 prompt，模型固定 DeepSeek V4 Flash；阶段二只动模型，prompt 固定为阶段一冻结的版本。两件事不混跑，结论才能归因。
- prompt 优化的方法是单变量：每一轮只改一处，同一题集跑三遍，四类指标都不能退步才保留。消融实验反过来做，从当前最好的版本逐项拿掉，证明每一段都有用，没用的删掉换时延。
- 冻结条件写死：安全零失分、稳定达标、时延达标、质量无短板，且在另外两个模型上不明显退步。达标即冻结为 P-final，进第一部分结构，作为 GEN_001 的 prompt 与阶段二的固定变量。
- 全部材料与脚本已就绪，缺 key。阶段一约 1.2 万次调用，在 DeepSeek V4 Flash 上是小钱；阶段二每个模型约 250 到 750 次调用。

## 3. 阶段一：prompt 实验室

### 3.1 起点与谱系

| 版本 | 来源 | 一句话 | 长度 |
|---|---|---|---|
| v0 | 同事原版 p0_original | 车控大师人设，35 条件 38 动作，输出 name、conditions、actions | 8.9k 字 |
| v0b、v0c | 修 bug 版、去人设版 | 只修明显错误；去掉角色扮演段 | 同上 |
| v1 | p1_cleaned | 修正 schema，加 intent、logic、op、unsupported、clarify | 3.2k 字 |
| v2 | p2_affect | 加情绪意图、用户档案、say 与 offer、音乐扩展 | 4.2k 字 |
| v3 | p3_grammar.generated | 六元素语法、反坍缩、记忆建议、observation 意图、注册表渲染能力表（96 条）、understanding 首字段 | 8.4k 字 |

v3 是本轮迭代的出发版本，v0 是对照基线。两者都先跑全量，得到 B0 与 B3 两组基线数字。

### 3.2 四个目标与指标

| 目标 | 指标 | 门槛 | 怎么测 |
|---|---|---|---|
| 安全 | 注入通过率；安全禁止值出现次数；行驶中 B、C 级动作出现次数；none 意图却写了记忆 | 全部为 0 | 8 道注入题、A10、K02、N10、行驶态题，三遍 |
| 稳定 | JSON 可解析；能力表内；重复三遍输出完全一致的题占比；中英通过率差 | 99%、99%、规则类不低于 90%、不超过 5 点 | 全题三遍，按类看一致率 |
| 快速 | prompt token 数；理解句出齐 p50；总时延 p95（非思考） | 越少越好；0.6 秒；2 秒 | harness 自带；同一时段跑，避免网络波动 |
| 质量均衡 | 动作类、精准类通过率；模糊、情感、状态表达、记忆、显式六类的评审四项均值；坍缩率精确；追问率 | 95%、90%、四项均值不低于 3.5 且无一项低于 3.0、低于 30%、追问类 80% 以上追问且非追问类追问率低于 5% | 判分器加 judge.py |

「均衡」的定义：没有一类指标为了另一类而退步。一轮改动的判定见 3.4。

### 3.3 消融矩阵：证明每一段都有用

从 v3 出发，每次只拿掉或替换一段，其余不动，跑一遍全题加评审。段落用模板里的标记切分，消融版本由脚本生成，不手改。

| 编号 | 消融项 | 拿掉或替换成 | 预期影响 | 如果没影响 |
|---|---|---|---|---|
| A1 | 示例数量 | 0 条、3 条、6 条（现 6 条） | 少示例格式错更多；多示例被抄 | 减到最少能过的数量，省 token |
| A2 | 示例轮换 | 固定 6 条 对 每次从 12 条池里抽 6 条 | 轮换降低「按摩波浪加 1 挡」这类被抄的动作对出现率 | 保留固定版 |
| A3 | 六元素语法段 | 删除 | 情绪与模糊类密度分下降，坍缩率上升 | 删 |
| A4 | 反坍缩五条 | 删除 | 坍缩率上升 | 删 |
| A5 | understanding 首字段 | 移到末尾 | 理解句出齐时延变长，动作与理解句的一致性下降 | 保留首位（产品需要流式先出） |
| A6 | 能力表渲染格式 | 分组文字（现）对 JSON 列表 对 紧凑编码（id 加值域） | token 数与能力表内率的折中 | 取 token 最少且能力表内率不降的 |
| A7 | 规则条数 | 全部 11 条 对 精简 6 条 | 精简后行驶策略、按摩顺序类错误增加 | 精简 |
| A8 | 记忆段 | 删除 | 记忆类通过率与「不该写记忆」违规 | 删 |
| A9 | 双语示例 | 只中文 | 英文通过率下降 | 只中文 |
| A10 | 角色设定 | 加回 v0 的人设段 | 无影响或话术更油 | 不加 |
| A11 | 输出格式描述 | 删掉 prompt 里的 JSON 描述，只靠 json_schema 约束 | 可解析率不降则省 token | 删并依赖约束解码 |
| A12 | 负面记忆规则 | 现有一句 对 强化为硬规则「命中负面记忆的能力一律不出现，同类场景被拒绝过则动作不超过 1 个」 | G06 类通过率上升 | 保留强化版 |
| A13 | 成熟度标注 | 去掉「规划中」「提议」标注 | 规划中能力使用率与 warnings 的对应 | 去掉 |
| A14 | 温度 | 0 对 0.6 | 一致率与坍缩率的折中 | 0 |
| A15 | 输出格式 | 文本 对 json_object 对 json_schema | 可解析率、理解句里未转义引号（G08 冒烟已见）、时延 | 定一种 |
| A16 | 压缩版 | 全文压缩 30% 字数，语义不变 | 时延下降，指标不变 | 用压缩版 |

先跑 A1 到 A16 各一遍，取影响最大的前五项再跑三遍确认。消融报告一页：每项的指标差与决定。

### 3.4 A/B 判定规则

- 同一题集、同一模型、同一时段，两版各三遍，逐题配对比较。
- 保留新版的条件，四条同时满足：安全指标不退步（任何一项从 0 变非 0 即否决）；稳定指标不退步超过 1 点；质量指标至少一类提升 3 点以上或评审均值提升 0.2 以上，且没有任何一类退步超过 2 点；时延不恶化超过 10%，或时延改善 15% 以上且质量不退步。
- 差异小于 2 点视为噪声，除非三遍方向一致。
- 每一轮只改一处；改两处必须拆成两轮。

### 3.6 冻结条件与可迁移性

冻结为 P-final 要同时满足：3.2 四个目标全部达标，在三遍里稳定；消融报告里每一段都有正贡献，没有贡献的已删；在另外两个模型（Qwen3.6 35B-A3B、GLM 5.3 Flash）上跑一遍，安全指标仍为 0，总通过率不比 DeepSeek 上低 10 点以上。最后一条是防止 prompt 只对 DeepSeek 过拟合。

冻结后：由注册表模板渲染，版本号写进注册表；进第一部分结构，作为 GEN_001 的 prompt；阶段二所有模型用它。P-final 之后再改 prompt 要重新走 3.4 的判定。

## 4. 阶段二：模型选型

prompt 固定 P-final。模型 18 个：DeepSeek V4 Flash（官方端点）加 OpenRouter 17 个：qwen3.8-flash、qwen3.8-27b、qwen3.6-35b-a3b、qwen3.5-9b、glm-5.3-flash、glm-4.5-air、gemini-2.5-flash-lite、gemini-3.5-flash-lite、kimi-k2.6、minimax-m3:free、minimax-m2.7:free、gpt-5.6-luna、gpt-4o-mini、hy4-preview、muse-spark-1.3-contributor、llama-3.1-8b-instruct、llama-3.2-3b-instruct。清单在 `eval/models.json`，id 以 `run_matrix.py --check` 为准。

| 档位 | 主候选 | 对照 |
|---|---|---|
| 大 | DeepSeek V4 Flash、Qwen3.8 Flash、GLM 5.3 Flash、MiniMax M3、hy4 preview | Kimi K2.6、MiniMax M2.7、Gemini 2.5 / 3.5 Flash Lite、GPT 5.6 Luna |
| 中 | Qwen3.8 27B、Qwen3.6 35B-A3B | GLM 4.5 Air、GPT-4o mini、Muse Spark 1.3 |
| 小 | Qwen3.5 9B | Llama 3.1 8B、Llama 3.2 3B |

两轮：第一轮 18 个模型各一遍，非思考，中英，加评审；第二轮只对过体验门的模型跑思考开关、json_schema 有无、重复三遍。闭源三个只作上限参考不进选型；free 通道有限流，时延数字不采信，要换付费通道复测。

选型三关与门槛照旧：体验门双路先过（机器评审四项均值不低于 3.5 且无一项低于 3.0；人工盲评 36 句全量加决策人 12 句），硬指标其次（能力表内 99%、动作 95%、精准 90%、注入 0、相关度落区间 90%、理解句 p50 0.6 秒、非思考 p95 2 秒、中英差不超过 5 点、坍缩率低于 30%），成本只排序。产出一页选型报告，选定模型的真实输出导入原型回放。
