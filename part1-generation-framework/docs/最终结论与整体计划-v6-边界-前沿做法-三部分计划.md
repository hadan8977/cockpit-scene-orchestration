# 最终结论与整体计划 v6：边界、最前沿做法、三部分计划

2026-09-03。综合你公司 agent 的报告（已存 `notes/company-agent-report.md`）、我此前的 v1 到 v5 和本轮核实的两篇论文。先答核心问题，再给三部分的计划，然后我们分别把第一、第二部分做出来。

## 一、核心问题的回答

**问：自动的自定义座舱场景编排，交给车控 Agent 还是场景大脑？边界在哪？弱意图怎么办？**

1. **交给场景大脑，车控 Agent 不长编排能力。** 进场景大脑的判据三条，任一成立即进：组合度，要动两个以上原子能力；持久性，要留下可复用、可触发的对象；表达类型，说的是状态或目标，不是动作。“我好冷”三条都不满足：单动作、即时、可由车端温度补全，留在车控 Agent 快路径，1.5 秒内完成。“我好冷，还有点困，弄个舒服点的环境”满足组合度，进场景大脑。
2. **弱意图里的非业务表达（我好累、我和她今天纪念日），今天落闲聊 Agent，只给共情文字。要的增量是：闲聊照常答话，同时异步让场景大脑判断并生成卡片。** 三态：沉默、一句话邀请、卡片。卡片一键应用是安全边界，默认不自动执行。
3. **显式的“我想要一个我好累的场景”直达场景大脑。** 现有 002 需求的句式已经覆盖，只是被锁在场景编排页面里，放开到任何语音入口即可。
4. **最前沿的做法**，按 2026 年的论文和业界实践：把“要不要”和“做什么”合在场景大脑的一次调用里，输出相关度、意图、理解句和场景，前面只放一个便宜的预筛，不再单独训一个路由模型；门控用 PASK 的三态决策加 ProAct 的价值门控加预算上限；记忆作为生成素材注入，不只是检索；能力表走注册表热更新；验证器在模型外裁决。两篇论文本轮已核实：[PASK](https://arxiv.org/abs/2604.08000) 提出需求检测、记忆建模、主动系统三段式，配 LatentNeeds-Bench；[ProAct](https://arxiv.org/abs/2605.25971) 用空闲算力预判需求，价值门控决定要不要出手，在 ProActEval 上减少 14.8% 轮次、11.7% 用户投入、28.1% 幻觉。
5. **架构改动的最小集，四根线，不动骨架**：NLU 加 scene 域接显式请求；Master Agent 或闲聊 Agent 加一条异步旁路接隐性请求；小塔记忆对场景大脑开读接口；场景大脑接注册表与验证器，执行经车控、娱乐、地图 Agent。

## 三、三部分计划

**第一部分，25%：prompt 优化与云端小模型选型，作为场景 app 内的功能**

- 目标：把同事的 prompt 变成场景 app 内“一句话生成场景”的量产候选，并选出云端小模型，在速度、安全、稳定、质量之间取平衡。
- 做法：P3 契约，能力表由注册表渲染；约束集只留七条，闭集能力用 schema 约束解码、动作数上限、话长上限、安全禁止值、行驶策略、表外走 unsupported、注入走 none；其余交给评测说话。
- 候选模型，中英都测：DeepSeek V4 Flash 为主；Qwen3 Flash 系列、豆包 Seed Flash、GLM-4.7-Flash、Kimi K2.7 highspeed 为对照；公司内的 hy4 一并纳入。以能拿到 key 的为准。
- 实验：六个 prompt 变体、思考开关、json 模式、74 题中英全跑、三次重复、8 道注入题。选型准则：能力表内 99% 以上，动作类 95% 以上，精准类 90% 以上，情感类人评贴切 80% 以上，注入失分为零，非思考 p95 不超过 2 秒，再比成本。
- 产出：注册表生成的 prompt、一页约束文档、一页选型报告、题集与脚本（已有）。
- 工期 1.5 周。需要各家 key。

**第二部分，65%：demo，回答核心问题**

- 目标：一个可点可说的座舱模拟 demo，让人相信三件事。边界正确，同一句话各走各路，路由过程看得见；弱意图能长出卡片且有分寸，三态、价值门控、预算；卡片由记忆驱动且一键应用，两个人物说同一句话得到不同的卡片。
- 范围：中英；车内加手机的日历、身份、通知；不做家居。
- 组成，对应你的架构图：Vehicle Client 模拟，状态面板、卡片、灯语、语音气泡；Gateway 与 ASR 用文本输入，可选浏览器语音；NLU 用规则加小分类器，四档意图加 scene 域；中控分发表照你的图；车控 Agent 规则执行；闲聊 Agent 用小模型答话；场景大脑用 P3 一次调用加注册表、验证器、记忆包；状态服务可拨；记忆服务分型条目可看可删；场景引擎负责触发、执行、日志。
- 演示脚本八拍：“我好冷”走车控；“我好累”三态出卡片；“我和她今天纪念日”显式直达；“来点氛围”走舒适目标；演示中下线一条能力；换人后同一句话不同卡片；撤销并学习；离车报告。
- 评测：E7 隐性触发 200 条中英样本的精确率；卡片四件套指标面板在 demo 里可模拟。
- 工期 4 周：W1 骨架，分发表、状态、记忆、卡片；W2 场景大脑接入，两个例句跑通；W3 门控、预算、记忆驱动、热更新；W4 脚本、打磨、指标面板、报告。

**第三部分，10%：展望，只出计划**

- 架构：端侧 LoRA 适配器做离线创建；预筛并入 Bert 层；DMS 与情绪等多模态进状态服务；跨车的账号级记忆。
- 应用：车、手机、家的场景延伸；创作者包与季节包；区域包出海；口令与分享。
- 评审门：等 P1 的采纳率和打扰率数据出来再排优先级。
