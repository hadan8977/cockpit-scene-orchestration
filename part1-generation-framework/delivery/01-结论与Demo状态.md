## 什么时候可以说第一部分 Demo 完成

必须把这次实验成果接入交互应用，完成以下闭环并留下同一版本的验收记录：

1. 用户输入 → 固定 DS V4 Flash + p13 → 实际流式理解句 → 完整 JSON → 外部校验 → 场景卡。记录实际模型、Prompt 哈希、参数和端到端时延。
2. 中文、英文、续改、追问、拒绝、超时和取消均可走通；真实模型模式与示例模式清楚区分。
3. “应用一次”和“保存”分开；局部修改保留无关字段；保存后刷新恢复；非法条件不能被裁成无条件执行。
4. 在运行服务中下线一项能力，验证新生成、已有提案和执行前校验的一致行为；冻结 p13 不等于运行时热更新已经打通。
5. 固定一版应用执行端到端走查与真实模型回归；未达指标如实报告，人工体验评审单列。

跨模型选型、PRD 中的 scene 域语料扩写仍未完成。用户本轮优先限定在 DS V4 Flash Prompt，因此这些没有冒充为已完成；其后是否继续，见[后续计划](05-进度与后续计划.md)。
