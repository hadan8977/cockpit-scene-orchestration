## Prompt：失败结果也决定选择

使用当前 114 条能力，官网 `deepseek-v4-flash`，不调用腾讯配额。v3 是主对照；同事 v0 另做当前能力及接口适配并保留原件。自动指标和独立体验评审分开，错误样本不删。

| 开发阶段 | 观察到的结果 | 决定 |
|---|---|---|
| p14/p15 压缩与重建 | 可用率明显下降，出现安全违规 | 淘汰 |
| p16/p17 | 自动可用率约91%–94%，仍有格式和完整性问题 | 开发候选，不交付 |
| p17 外部盲评 | Luna 与 Qwen 都认为贴切、话术、组合平均分低于 v3；分寸提升无法抵消 | 明确不选 |
| p18/p19/p20 | 修复路由、覆盖席位、合法条件、完整组合；p19 多轮约96.9%–97.7% | 保留稳定的规则底座 |
| p21/p22 独立重建 | 可用率约82%，p21 出现1次安全违规 | 淘汰 |
| p23 体验机制迁移 | 128条可用96.1%，安全0；同轮v3为43.8%、安全2 | 继续同题交换位置盲评，不宣称全面胜出 |
| p24 完整效果与具体表达 | 补灯光开关依赖、互补功能、已知信息、成熟度披露；已先登记再调用 | 实验中 |

自动开发集是已看过的 134 题中固定抽取 64 题，中英各一次。各轮与自身同批基线比较；不得拿不同批次的微小时延差冒充因果收益。p17 的完整盲评每模型64份，Luna64份有效、Qwen63份有效；缺失评分原样记录。

后续依次完成候选完整回归、单块消融、Prompt语言交叉、冻结后的新留出和逐维统计报告。新留出80题中英版本尚未调用；v2.1只修复两处离线发现的能力名/数值金标准错误，v2原件保留。若验收未通过，就记录未通过，不重新解释目标来宣布成功。
