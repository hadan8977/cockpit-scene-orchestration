# 评审模型不是事实金标准

Luna、Qwen 均按预登记通过了最初四组、交换位置后八份校准：明显无关/违规动作、单控范围、相同输出、虚构能力。后续完整能力表一直随样本送入，但开发盲评仍出现明确的理解错误。下列是本代理的离线核查，**不是独立人工评分**，没有据此替换模型分数或重新请求到满意。

| 例子 | 原始理由中的问题 | 影响 |
|---|---|---|
| p23，Luna，N04-en-BA | 把“任意座椅有人”视为“后排有人”的正确条件 | 基线扩大触发范围，却可能得到更高贴切分 |
| p23，Qwen，C09-zh-AB | 把“已开启净化”视为正常确认，忽略生成阶段尚未执行 | 可能奖励不真实的执行表述 |
| p23，Qwen，E03-en-BA | 因按摩的sprint状态与“规划中”中文标签不一致扣分 | p24改用“尚未上线，仅供提议”，避免误标具体成熟度；原分数保留 |
| p24，Qwen，N05-zh-AB | 认为planned与“尚未上线，仅供提议”不一致，且空warnings不误导 | 该条同时输出三个顶层JSON对象，按预登记记无效，无分数插补；这也说明能力语义未必被正确理解 |
| p24，Luna，A10-en-BA | 输出大量空白，耗尽2300输出token | 按调用失败保留；不能将其空结果当平局 |
| p24，Qwen，F05-zh-BA | 缺preference，未满足完整评分schema | 保留为无效，不从已有两组分数推造偏好 |

因此报告同时提供：自动能力/契约检查、原始模型理由、评分覆盖率、AB/BA位置诊断、按输入语言拆分、题级区间和Holm校正。四维分数是两位机器评审在当前量表下的证据，不是“客观体验真值”。两个评审不一致或缺覆盖时，不宣布已证实全面胜出。

后续完整确认仍沿用同一v1量表以保持可比性。若需要修订量表或引入新评审，应先登记、更广校准、两臂全量重评并另报版本；不能只改对候选不利的样本，也不能抹掉这里的反证。
